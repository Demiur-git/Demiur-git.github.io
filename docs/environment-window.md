# 环境信息悬浮窗

右下角时钟入口打开信息窗；默认收起，刷新后仍收起，站内 Swup 切页保留展开状态。拖动顶栏或在顶栏聚焦后按方向键移动（Shift 加速）；Esc 或叉号收起。“重置窗口位置”恢复默认位置。窗口位置和手动选择的城市只保存于当前浏览器，不传给本站服务器。

北京时间按设备时钟转换至 `Asia/Shanghai`，不是标准授时校准。电量通过浏览器 Battery API 读取；浏览器不支持或读取失败会明确提示，台式机可能报告满电及接电状态，不能视为设备一定装有电池。

城市搜索与天气来自 Open-Meteo。选城前不发起请求；城市搜索最多显示五个结果。定位只在点击“使用当前位置”后申请权限，不调用 IP 定位、不持续追踪。定位结果先四舍五入至两位小数再发送给天气接口，并只保留在当前页面会话；刷新后恢复以前手动选定的城市（若有），不会记住定位坐标。

天气为接口提供的当前天气，不是设备现场测量。显示温度、体感、湿度、风速和北京时间数据时间，展开且页面可见时每 15 分钟刷新。手动刷新至少间隔 10 秒，失败后不无限重试；旧数据会标明更新失败。收起或切换后台停止计时及待执行请求，取消后返回可按需重新获取。

使用免密钥非商业接口，不需要新后端或环境变量。服务与地区网络访问不保证可用，失败时保留时钟、电量与选城功能，不自动切换第三方服务。网络查询不会携带本站 Cookie，也不向 API 发送本站 Referer。

参考：[Open-Meteo 天气](https://open-meteo.com/en/docs)、[城市搜索](https://open-meteo.com/en/docs/geocoding-api)、[Battery API](https://developer.mozilla.org/en-US/docs/Web/API/Battery_Status_API)、[Geolocation API](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API)。

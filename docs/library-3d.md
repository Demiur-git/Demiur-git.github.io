# 线稿图书馆（本地测试版）

参观网址仍为 `/library-3d/`。主页音乐栏下方提供“空间阅览”窗口，点击“进入 3D 阅览”即可参观，无解谜门槛。窗口使用自包含静态 SVG，不提前加载 Three.js 或创建画布；手机位于馆藏目录与音乐栏之后。页面保持 `noindex`，不加入顶栏、搜索与 sitemap；这不是访问认证，不能存放私密内容。

打开直接站在一楼大厅入口。电脑用 `W/A/S/D` 行走、按住鼠标拖动转向，方向键转向；按住左／右 Shift 奔跑。手机左侧摇杆行走、右侧滑动转向，摇杆上方有“按住奔跑”，三者可同时操作。步行 2.6m/s、奔跑 4.55m/s；保持离地 1.65m 的眼高，随楼梯连续升降；斜向不加速，不能穿过墙体或家具，不飞行、不跳跃、不自动抖动。旧馆外、环绕、缩放、入馆按钮及过渡均已移除。

实际持续跑动约 12 秒后，绫提醒：“嘘……图书馆里最好不要跑闹，慢一点好吗？”提醒显示约 5 秒，不停下行走、不抢焦点；45 秒冷却，步行或停下超过 2 秒重置连续计时，撞墙不累计。后台暂停、失焦清键；计时仅在本次参观内保留。

大厅后方通往净宽 2.8m 的同层走廊，四间功能房约 7×8m，常开门洞净宽 1.5m。从入口向走廊看：

| 房间 | 位置与陈设 | 现有栏目 |
| --- | --- | --- |
| 档案室 | 左前：档案柜、登记桌、带三份记录的目录桌 | 书库、便签、日历 |
| 音乐室 | 右前：唱机、唱片架、聆听座椅 | 音乐 |
| 展览室 | 左后：画框、展柜、项目工作台 | 相册、项目 |
| 工具室 | 右后：索引柜、工具登记台 | 工具导航 |

走近功能物件约 2m、面向且未被墙体、家具或楼板遮挡时，显示对应入口；不能隔层触发。电脑按 E 或点击，手机轻点，只打开馆内确认卡：物件名称、目标介绍、“继续参观”和“前往页面”。默认焦点在继续参观，Tab 仅在卡内循环，Esc 取消。卡片期间停止移动、转向和奔跑计时；取消保留机位，清除仍按住的操作。确认后才经 Swup 离场；禁用页面不显示入口，唱机不创建新播放器。失败保留卡片与位置，可重试或取消。确认卡不会提前恢复音乐。

后走廊末端新增折返楼梯，二楼地面高 4.4m。导航使用连续坡面，视觉保留踏步与扶手；楼梯按空间距离等速移动，不逐级跳动。平台可以正常转向往返，不能穿扶手、跨越栏杆或切换到未连接的楼层。二楼回廊连接大厅后侧观景栏廊与员工休息室，不增加整套二楼功能房。家具采用确定性的错落位置和朝向，绘制、碰撞、入口共用定义，不在重进时随机变化。

二楼的三个入口：员工休息室资料桌上个人档案进入 `/about/me/`，馆员资料进入 `/about/ling/`；回廊公告栏进入 `/about/site/`。休息室保留沙发、茶几、座椅与储物柜；不增加人物模型或对白，也不改三个“关于”页面。

「操作说明」内提供阅读区观赏位置。可以重置到入口或返回主页；Esc 优先取消确认卡，其次关闭说明，再次按下离开。刷新回到入口，不写入浏览器探索进度。

固定纯黑底、白／灰线条，不跟随网站主题改变画面。保留入口、中央阅读区、两侧书架过道和窗边座位，用主轮廓、结构线、细节线三个层级绘制建筑插画：书架线脚、书脊装帧、窗框分格、桌椅接合、平滑灯罩、书页与植物叶脉。远处细节逐渐减淡。黑色几何只用于遮挡背后的线，不显示实体材质、三角网格、光照、阴影或贴图。

空间仍保留透视和碰撞，不是平面插画或把背景图贴在墙上。现有壁纸作为构图参考，不承诺逐像素复刻；原图和序章素材不修改。

维护入口：

- `src/utils/library-3d-layout.ts`：米制尺寸、两层地面与楼梯、房间与门洞、家具朝向、身体碰撞与三维视线、功能入口。布局由绘制和碰撞共用；移动家具时同步其入口位置。
- `src/utils/library-3d-model.ts`：精选轮廓、曲线、局部排线、三层线宽和距离淡化，实例化黑色遮挡几何；不请求远程模型或纹理。
- `src/utils/library-3d-scene.ts`：相机、键鼠／三点触控、碰撞、投影铭牌、功能入口及资源释放。
- `src/utils/library-3d-running.ts`：不依赖浏览器的有效跑动、提醒时长与冷却逻辑。
- `src/styles/pages/library-3d.css`：固定黑白控制界面和失败回退。

只在该隐藏页加载现有本地 Three.js，未新增依赖。需要 WebGL2；不支持、上下文丢失或加载失败时显示明确提示、原图参考、重试及返回。参考图不是当前线稿画面。手机像素比最高 1.5，桌面最高 2；静止时不重复绘制，后台暂停，减少动画仍能主动参观。

音乐沿用其他隐藏场景的暂停与条件恢复：真正离开探索后，仅原曲未改变且入场前正在播放时尝试恢复。切页、前进后退及退出时释放控制器、GPU 资源、监听和滚动锁。

检查：`pnpm exec tsx --test scripts/library-3d.test.ts`、`pnpm check`、`pnpm type-check`、`pnpm build`。线稿测试覆盖确定性、有限坐标、分层绘制、资源释放、房间连通、等速／斜向奔跑、高速碰撞、入口范围／朝向／遮挡／开关、提醒与冷却；浏览器检查包括三个屏幕尺寸、两种网站主题、键鼠／三点触控、连续进出、音乐恢复、历史、减少动画、WebGL 失败与恢复。软件渲染指标不代表手机实测帧率，仍需实体设备体验。

本轮不提交或推送，保留原有订阅页、曲库及私有对话表格。

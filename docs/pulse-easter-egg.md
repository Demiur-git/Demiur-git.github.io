# 隐藏彩蛋（维护说明）

这份说明面向维护者，不是公开线索页。`/pulse/`、`/newworld/` 与 `/starfield/` 不出现在菜单、站内搜索或 sitemap，均设置 `noindex, nofollow`。静态网站的浏览器进度和密码不是安全认证，不能用于保护私密内容。

## 线索维护

- 内部数据和提示：`src/config/pulsePuzzle.ts`。
- 进度及仿射映射：`src/utils/pulse-puzzle.ts`。
- 遗留物件：`src/components/features/PulseClue.astro`。
- 扫线与摩斯：`src/components/features/PulseScene.astro`、`src/utils/pulse-scene.ts`、`src/utils/pulse-wave.ts`、`src/utils/pulse-morse.ts`。
- 王座场景：`src/components/features/NewWorldScene.astro`、`src/utils/new-world-scene.ts`、`src/utils/throne-geometry.ts`。
- 星空场景：`src/components/features/StarfieldScene.astro`、`src/utils/starfield-scene.ts`、`src/utils/starfield-geometry.ts`。
- 共享生命周期、滚动与音乐：`src/utils/easter-egg-scene.ts`、`src/utils/easter-egg-session.ts`。

主页折角开启探索，其余物件随后可见。数字分别放在主页折角、书库第一张借书卡的旧凭条、归档边注、日历页脚印章、工具导航分组下方的索引贴。栏目链接与线索按钮独立。为迁移旧记录，内部数字 ID 仍保留 `home / archive / categories / tags / posts`，不代表现在的所在页面。

书库公告栏残纸是 `AF / 5`，日历残纸是 `FINE / 8`；归档边注还留有 `start:0`。界面不提供完整公式或解码示例。维护者已知规则为 `c=(5x+8) mod 26`，以 `A=0` 编号，按借阅序号排列的 `05 04 11 20 02` 反向映射为 `PULSE`。收齐五份数字及两块残纸才可在音乐页提交，大小写与首尾空格不影响结果；错误保留进度。

进度使用 `demiur-pulse-puzzle-v5`，兼容读取 `v1` 至 `v4`。旧 `v4` 已解锁 `/echo/` 的记录会自动视为读过项目页批注，不撤销已有解锁；其他旧记录不会自动得到这条线索。存储不可用时保持页面内存，刷新可能丢失。音乐页已解锁入口提供全部进度重置，以及单独的“重置第二条心跳”：后者只清除项目批注已读与 `/echo/` 解锁，不影响数字、残纸和摩斯分支。

## 场景与回退

白场一秒后，扫描头约四秒横扫一屏；随机振幅为 105–170 个 SVG 单位，普通绘图区为 40dvh、最大 400px，脉冲间隔 700–1150ms，余迹约 1.1 秒消失。整条波形不移动，不代表医疗测量。在线附近长按两秒进入摩斯模式，提前松开或移动取消；聚焦交互区域按住空格等价。摩斯模式恢复紧凑绘图区，上键或「↑ ·」添加短脉冲，下键或「↓ —」添加长平直段，Enter 或按钮确认字母，退格先撤销符号再撤销上一字母。快速输入排队显示，按键重复不追加。

第二条心跳的线索藏在项目页的两笔铅笔线里，只有展开批注才记录已读；仅访问项目页不算。未读批注时，心电图不显示灰痕，也没有可聚焦的灰痕触点。已读后约三轮扫描留下一截短灰痕，从那里拖动至少 20px 才进入共振；键盘可聚焦后用 Enter／空格选取、方向键牵引。减少动画模式不等待扫描。已解锁者可从灰痕直接重入 `/echo/`；单独重置后须重新读批注并完成共振。

摩斯暗号 **NEWWORLD** 与 **PALINGENESIS** 分别通向王座和星空，都只能通过摩斯字母组成，须独立提交；当前没有公开推导提示，不应宣称它们是可独立解出的完整谜题。错误保留输入，允许清空和收起。已解锁页面的再次进入链接仅在摩斯模式显示。

星空为纯黑背景上的程序生成三维白／灰星点，星区按空间坐标固定生成，可持续飞行而无边界。桌面使用 W/A/S/D、Q/E、鼠标拖动与滚轮；手机用左摇杆、右侧滑动及升降按钮。重置视角可回到初始位置。减少动画时不自动闪烁星点，主动飞行仍可用。Esc 与返回链接回到心电图，未解锁直接访问也回到心电图；渲染失败时保留返回入口。

新空间起初纯黑，点击产生暗环并显露白色实体王座背面。正面为白色，侧面浅灰、结构线中深灰，轮廓附微弱白光。底部改为闭合的实心底座，不保留椅腿或地面根须；顶部不再有枝条，靠背为纯白面，不保留内部条纹。周围共 44 条不同走向的触须，其中保留原有 28 条并增加 16 条 0.45–0.65px 的细丝，新增细丝向底座汇聚。固定连接点、缓慢起伏与短段深度排序保持不变，被实体遮住的线不穿过王座。

按住 W、上键或手机「前行」约四秒走近，松开停止；相机步伐约每秒 1.6 次、桌面 2px／手机 1px，上下起伏在起止时约 150ms 收放。王座远处约占屏高 12–15%，终点仍只占 28–32%，手机不超过屏宽 55%。到达后播放 `pulsePuzzle.worldDialogue` 中从「对话.xls」NEWWORLD 工作表收录的 17 句对白，默认手动；自动等待约 2.5 秒。在第四句后必须选择「你是谁？」才能继续，自动模式不会代选；最后一句仍须手动收起。

对白收起后显示中央「返回主页」选项，空白点击与自动推进都不代选。`src/utils/world-return.ts` 管理独立于页面内容的归返遮罩：柔和纸白从中央约 500ms 扩张至全屏，预先验证首页内容，再交给 Swup 切页，页面就绪后约 250ms 淡去；不触发开书或首页序章。加载失败撤回遮罩，留在王座并提供重试。重复操作只启动一次，隐藏页面暂停扩张与淡出。

两页轻点空白或按 Tab 显示返回，空闲三秒隐藏但聚焦期间保留；王座的隐藏入口标明「返回心电图」，Esc 仍采用这条退出路径。减少动画使用加强振幅的静态波形、固定细丝与光晕、即时输入反馈与远／中／近三个静止机位，归返采用合计约 120ms 的淡出入；隐藏页面暂停扫描与镜头。

场景共用原播放器：第一次入场暂停，隐藏页面之间保持暂停；真正退出探索时，仅原曲未改变且入场前正在播放才尝试恢复。浏览器拒绝播放时保持暂停。未解锁直达王座或星空返回心电图，未解锁直达心电图返回音乐并提示寻找线索。无 JavaScript 时提供静态返回链接。

进出两页不触发开书；从它们返回主页也不触发序章。原有其他页面、音乐文件和角色对白不改动。取消、断开与浏览器恢复统一清理并重新建立监听、逐帧绘制、滚动锁和焦点。

校验：`npx tsx --test scripts/pulse-puzzle.test.ts scripts/pulse-morse.test.ts`、`pnpm check`、`pnpm type-check`、`pnpm build`。浏览器还需检查实际鼠标、触屏、长按取消、键盘输入、切页历史、音乐恢复与 1440／768／390px 亮暗布局。
